Attack Vectors 1 & 2

Control Plane & Supply Chain Threats

1. Misconfigured API Server & Over-Privileged RBAC
  • Vulnerability: Publicly exposed port 6443 or wildcard RBAC permissions (* verbs, cluster-admin).
  • Attack Chain: Leaked service account token enables rogue pod creation and cluster-wide privilege escalation.
  • Real Case: Tesla cryptojacking attack via exposed unauthenticated Kubernetes dashboard.
  • Mitigation: Private API endpoints, strict OIDC, automated RBAC audit (Kube-Bench).
2. Insecure Supply Chain & Poisoned Images
  • Vulnerability: Base images containing known CVEs, untrusted registries, backdoored dependencies.
  • Attack Chain: Malicious image launches reverse shells or drops miners immediately upon pod initialization.
  • Real Case: Kinsing & Doki malware campaigns targeting public registries and Docker daemons.
  • Mitigation: Image signature verification (Cosign), CI/CD vulnerability scanning, and SBOM tracking.
Speaker Notes (1.5 min): Emphasize that static security in CI/CD is necessary but not sufficient. Highlight how exposed API servers and untrusted images provide attackers initial access.
Attack Vectors 3, 4 & 5

Runtime, Lateral Movement & Host Escapes

3. In-Pod RCE & SA Token Theft
  • Vulnerability: Web app flaws (Command Injection, LFI, Log4Shell).
  • Attack Chain: Exfiltrates token at /var/run/secrets/... to query K8s API directly.
  • Mitigation: KubeArmor file/process blocking, disable token automount.
4. Flat Pod Networking & Lateral Drift
  • Vulnerability: Default open pod-to-pod east-west connectivity.
  • Attack Chain: Compromised pod scans internal VPC, DBs, and cloud metadata (169.254.169.254).
  • Mitigation: Default-deny NetworkPolicies, eBPF microsegmentation.
5. Container Breakout & Host Escape
  • Vulnerability: privileged: true, hostPID, CAP_SYS_ADMIN or kernel CVEs.
  • Attack Chain: Escapes container namespace to gain root access on the K8s node.
  • Mitigation: Pod Security Standards (PSS), Seccomp, and BPF-LSM.
Speaker Notes (1.5 min): Detail how an attacker pivots once inside a pod: stealing the mounted JWT token, port-scanning internal namespaces, and leveraging container misconfigurations for host breakout.
