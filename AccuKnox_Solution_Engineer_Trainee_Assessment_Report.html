3. Zero-Trust Defense: KubeArmor Active Hardening

Remediation Strategy: By applying the custom KubeArmorPolicy (k8s-manifests/kubearmor-dvwa-security-policies.yaml), Linux Security Modules intercept unauthorized system calls at the kernel layer:

  • Command Injection Mitigated: Blocks /bin/sh and /bin/bash execution with -EACCES (Permission Denied).
  • Token Theft Mitigated: Blocks read access to /var/run/secrets/kubernetes.io/serviceaccount/* and /etc/passwd, stopping LFI credential theft.
